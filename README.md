# SASD Freelancer LaunchPad

Local Windows desktop application for managing and analysing freelance project opportunities.

## Purpose

SASD Freelancer LaunchPad helps freelancers track project opportunities, proposals, budgets, skills, notes and outcomes in a local Windows application.

The first version focuses on manual project tracking and local data storage. Automated imports or scraping are intentionally deferred to later versions.

## Planned MVP

- Manage freelance project opportunities
- Store platform, title, link, description, budget and skills
- Track status and notes
- Search and filter projects
- Use a local SQLite database
- Prepare later analysis of budgets, skills and proposal outcomes
